Entry for the [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5)
competition on make.fun: the one line a gamer texts the boss to skip
work on GTA 6 launch week, at most 20 words, judged pairwise by a
tired-manager AI judge on believability, humour, hurried-text feel,
and freshness.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> my landlord's replacing the front door today and i'm locked in until they finish, sorry

The excuse works because it is boring and specific (a landlord, a
front-door replacement) rather than a wild story, and the laugh comes
from its own logic: the gamer is locked *in*, not locked out — the one
direction that excuses the whole day instead of just the commute. In
87 characters and 15 words it lands on first read, with no setup, no
explanation and no signature, like a text sent in a hurry. The output
file is written world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
